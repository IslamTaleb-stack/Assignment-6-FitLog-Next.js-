# FitLog

A modern fitness workout library and tracking application built for the Assignment 6 project. Browse workouts, plan your training schedule, and save exercises for later — all in one sleek interface.

## 🛠️ Technologies Used

- Next.js 
- React 
- TypeScript
- Tailwind CSS
- Context API

## ✨ Key Features

1. **Workout Library** — Browse all available exercises with thumbnail previews, duration, calories, and ratings
2. **My Plan Management** — Add workouts to your daily plan, view live stats, and mark exercises as completed
3. **Saved Collection** — Store favourite workouts separately to build future training routines
4. **Sort & Organize** — Sort exercises by name, duration, or calories burned to find exactly what you need
5. **Persistent State** — Plan and saved items stay intact across browser sessions and page refreshes
